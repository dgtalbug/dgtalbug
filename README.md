#### 📚 Sharrd — An Engineering Knowledge Workbench

**Less memorizing. More understanding.**

I’m building Sharrd to help engineers explore the ideas behind code, connect language fundamentals with design and systems, and practice explaining their decisions.

Start with Java, Python or Go. Explore objects and contracts through low-level design, reason about algorithms, and work toward system-design trade-offs.

Core is available, LLD is partially available, and DSA and System Design are still taking shape.

[Explore the staging preview](https://staging.sharrd.cloud)
